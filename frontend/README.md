# Frontend

React + TypeScript + Vite web UI for the Meeting Intelligence Platform: create meetings,
upload audio, follow processing state, read the timestamped transcript with synchronized
audio playback, and jump from semantic entities to their source segments.

```bash
npm install
npm run dev       # development server
npm run build     # type-check and production build
npm run lint      # oxlint
```

The backend must be running; see the [root README](../README.md) for setup and configuration.
